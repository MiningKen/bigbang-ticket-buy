搶票助手（Windows 可攜版）
==========================

需要：Windows 10/11，以及 Google Chrome 或 Microsoft Edge。
不需要：安裝 Node.js、npm、Playwright 或其他套件。

使用步驟：

1. 將 ZIP 完整解壓縮到一般資料夾，不要直接在 ZIP 裡執行。
2. 雙擊 START-WINDOWS.cmd。
3. 等待「搶票控制台」小視窗開啟。
4. 選擇場次、票數、連號策略和票價順序，再按「儲存設定」。
5. 按「開啟登入頁」，在另外開啟的 Ticket Plus 視窗登入。
6. 控制台顯示「已登入」後，按「開始監看」。
7. 驗證碼、實名資料、座位確認與付款請本人完成。

寬宏 BIGBANG 高雄一般販售（9/22 10:00）：

1. 雙擊 START-KHAM-WINDOWS.cmd。
2. 按「開啟登入頁」，自行登入寬宏並確認實名制名單。
3. 選擇「1張」或「2張連號優先，失敗則1張」，再按「開始等待 9/22 10:00」。一般販售不需要信用卡前6碼。
4. 兩張模式依序嘗試：2/28兩張連號、2/27兩張連號、2/28單張、2/27單張；絕不接受兩張不連號。
5. 無票時每3到5秒使用官方「更新票數」並持續循環，直到符合條件、你按停止，或遇到需要手動處理的頁面。
6. 程式選到符合條件的票並按下一步後會通知你；請立刻自行確認實名資料並完成付款。

熱門票可使用「快速（5–8 秒）」監看。發現票券或需要本人接手時，控制台會顯示大型提示、播放警示音、嘗試送出 Windows 通知，並將購票視窗帶到前景。

關閉方式：關閉控制台視窗；若黑色命令視窗仍開著，可按 Ctrl+C。

注意：
- 請保留整個資料夾，勿只複製 START-WINDOWS.cmd。
- 第一次執行若 Windows 防火牆詢問，程式只使用本機 127.0.0.1；不需要開放公用網路。
- Windows SmartScreen 若出現提示，請先核對壓縮檔來源與 SHA-256，再決定是否執行。
- 程式不保證購票成功，也不會繞過排隊或驗證碼。
